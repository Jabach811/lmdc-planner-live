§ 03 · Audits

Six probes for what the load will reject.

Each query partitions by SSN and keeps the most recent employment row (term desc null-last, then hire desc) — so prior rehires don't mask current gaps.

01 If loading

Missing class codes

Filters CLASS_I = 0 on the latest row per SSN.

CORP.EMPLOYEE.CLASS_I
02 If loading for plan

Missing divisions

Filters EE_DIV_NO = ''. Pair with cross-ref to PE_DIV_EMPL_DATA.

CORP.EMPLOYEE.EE_DIV_NO
03 If loading for plan

Missing employee numbers

Filters EE_NO = ''. Latest row only.

CORP.EMPLOYEE.EE_NO
04 If loading for plan

05 Always

Missing gender code

Filters EE_SEX_CD = ''. Required for compliance reporting.

CORP.EMPLOYEE.EE_SEX_CD
06 Always

Missing payroll frequency

Filters EE_PAYROLL_FREQ_CD = ''. Drives deferral period math downstream.

CORP.EMPLOYEE.EE_PAYROLL_FREQ_CD
Latest-row pattern Every audit uses ROW_NUMBER() OVER (PARTITION BY SOC_SEC_NO ORDER BY EE_TERM_DT DESC NULLS LAST, EE_HIRE_DT DESC) and keeps rn = 1. Without this, a prior terminated employment row can hide a missing field on the current row.

Divisions

Term reason

Gender code

Payroll frequency

EE_PAYROLL_FREQ_CD = '' · drives deferral math.

§ 04 · SQL

The core pull, verbatim.

Reformats date columns and joins address. Replace QK63283_ 00073% with the target case prefix.

-- VERIFY IF DATA EXISTS IN TABLE BEFORE LOADING; USE TO DO INDIVIDUAL PPT RESEARCH TOO.
SELECT *
FROM CORP.EMPLOYEE
WHERE CASE_NO LIKE 'QK63283_  00073%';

-- CENSUS DEMOGRAPHIC DATA
SELECT A.CASE_NO, A.SOC_SEC_NO, EE_LAST_NM, EE_FST_MID_NM, A.MIDDLE_NM, A.SUFFIX_NM,
       DATE_OF_BIRTH, DATE_OF_HIRE, DATE_OF_TERM, EE_REHIRE_DT,
       STREET_NM, ADDR_LINE_2_T, CITY_NM, ST_CD, ZIP_CD, COUNTRY_NM, COUNTRY_C,
       EE_PAYROLL_FREQ_CD, EE_SEX_CD, PHONE_NO, EVE_PHONE_NO, MOBILE_PHONE_NO,
       EE_CYC_DT, MOD_TS, USER_I
FROM (
  SELECT CASE_NO, SOC_SEC_NO, EE_LAST_NM, EE_FST_MID_NM, MIDDLE_NM, SUFFIX_NM,
    CASE WHEN substr(EE_BRTH_DT,5,2)||'/'||substr(EE_BRTH_DT,7,2)||'/'||substr(EE_BRTH_DT,1,4) = '00/00/0000' THEN ''
         ELSE substr(EE_BRTH_DT,5,2)||'/'||substr(EE_BRTH_DT,7,2)||'/'||substr(EE_BRTH_DT,1,4) END AS DATE_OF_BIRTH,
    -- (DATE_OF_HIRE, DATE_OF_TERM follow the same pattern)
    EE_REHIRE_DT, EE_PAYROLL_FREQ_CD, EE_SEX_CD, EE_CYC_DT, MOD_TS, USER_I
  FROM CORP.EMPLOYEE
  WHERE CASE_NO = 'QK63283   00073'
) AS A
LEFT JOIN (
  SELECT CASE_NO, SOC_SEC_NO, STREET_NM, ADDR_LINE_2_T, CITY_NM, ST_CD, ZIP_CD,
         COUNTRY_NM, COUNTRY_C, REGION_ST_CD, PHONE_NO, EVE_PHONE_NO, MOBILE_PHONE_NO
  FROM CORP.EE_BEN_ADDRESS
  WHERE CASE_NO = 'QK63283   00073'
    AND PAYEE_TYP_CD = '1'
) AS B
  ON A.CASE_NO = B.CASE_NO AND A.SOC_SEC_NO = B.SOC_SEC_NO
ORDER BY SOC_SEC_NO
FOR FETCH ONLY WITH UR;
six audits follow
-- Pattern reused for class, division, EE#, gender, payroll-freq
SELECT  CASE_NO, SOC_SEC_NO, EE_FST_MID_NM, EE_LAST_NM,
        EE_BRTH_DT, EE_HIRE_DT, EE_TERM_DT, <COLUMN>
FROM (
  SELECT e.*,
    ROW_NUMBER() OVER (
      PARTITION BY SOC_SEC_NO
      ORDER BY
        EE_TERM_DT DESC NULLS LAST,
        EE_HIRE_DT DESC
    ) AS rn
  FROM CORP.EMPLOYEE e
  WHERE e.CASE_NO LIKE 'QK63283_  00073%'
    AND e.<COLUMN> = ''   -- or = 0 for class
)
WHERE rn = 1;
