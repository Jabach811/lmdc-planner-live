§ 01 · Flow

Pull, classify, copy.

A participant's election history is layered. Take only the latest EFF_D per ENRL_PROV_GRP_I + PART_ENRL_I, then resolve whether each row was elected or merely defaulted.

Step Core query Output / variant
§ 01b · Default status

Three ballots, three verdicts.

After the LEFT JOIN to PART_PPA_DEFAULT, every election row resolves to one of three states. The null state is the most common — and the easiest to misread.

DEFAULT_STAT_C = 0

Not in Default

Participant made an explicit election. Their fund choices are real selections — copy them as-is.

DEFAULT_STAT_C = 1

In Default

Participant is sitting on the plan's default election. Carry the default forward, not the underlying allocation.

no row joined · NULL

Status unknown

No record in the default table at all. Investigate before loading — this is usually a missing PPA enrollment, not "no default."

§ 03 · Defaults

What DEFAULT_STAT_C resolves to.

The COALESCE block on the join produces one of three labels per election row, evaluated only where ENRL_SERV_TYP_C = 2.

DEFAULT_STAT_C = 0
Not in Default

Participant elected this rate explicitly. Carry it forward as-is.

DEFAULT_STAT_C = 1
In Default

Auto-deferral default rate is in effect. Verify the receiving plan's default before copying — a different default rate means rebuilding, not copying.

No row joined
NULL

Participant predates the PPA default tracking, or the join key didn't resolve. Treat as an electing participant.

Save Express — three-step build (1) CREATE TABLE SAVEXPRESSCOPY with the layout shown. (2) Upload NEW account number, SSN, DEF_ADJ_P, DEF_ADJ_A and SRC_I to that table. (3) Run the four UPDATE statements to populate EE_DIV_NO, ENRL_PROV_GRP_I, PART_ENRL_I, EFF_D, DEF_GRP_I, DIV_I. Only then run the INSERT into PART_AUTO_DEF.
§ 04 · SQL

Current elections — single case.

Replace UN62203 00001 with the prior account; replace SSN with the participant under research, or comment that line and the script returns the whole plan.

SELECT account_no, soc_sec_no, a.SRC_I, a.ELEC_TYP_C, a.FD_DESC_C, a.ELEC_P,
       eff_d, a.SRC_S, a.SRC_C, a.INPUT_SRC_C, a.USER_I,
       COALESCE(CASE
         WHEN b.DEFAULT_STAT_C=0 AND ENRL_SERV_TYP_C=2 THEN 'Not in Default'
         WHEN b.DEFAULT_STAT_C=1 AND ENRL_SERV_TYP_C=2 THEN 'In Default'
         ELSE 'NULL'
       END, 'NULL') AS default_ind,
       CASE
         WHEN a.src_i=0 THEN 'ALL SOURCES'
         ELSE (SELECT REPORT_1_NM||REPORT_2_NM FROM pension.plan_src_detail c
                WHERE c.src_i=a.src_i)
       END AS src_txt
FROM pension.part_elect_detail a
LEFT JOIN pension.part_ppa_default AS b
  ON a.enrl_prov_grp_i = b.enrl_prov_grp_i
 AND a.part_enrl_i      = b.part_enrl_i
 AND ENRL_SERV_TYP_C    = 2
WHERE account_no = 'UN62203   00001'
  AND EFF_D IN (SELECT MAX(eff_d) FROM pension.part_elect_detail c
                 WHERE c.ENRL_PROV_GRP_I = a.ENRL_PROV_GRP_I
                   AND c.PART_ENRL_I    = a.PART_ENRL_I)
  AND SOC_SEC_NO = '283-66-4214'
  AND ELEC_TYP_C = '0';
save express copy — three steps
-- (1) Drop + create
DROP TABLE SAVEXPRESSCOPY;
CREATE TABLE SAVEXPRESSCOPY (
  PART_ENRL_I      DEC(17),  ENRL_PROV_GRP_I DEC(17),
  ACCOUNT_NO       CHAR(20),  SOC_SEC_NO       CHAR(11),
  EFF_D            DATE,     DEF_ADJ_P        DEC(6,3),
  DEF_ADJ_A        DEC(15,2), SRC_C            CHAR(1),
  DEF_GRP_I        DEC(17),   DIV_I            DEC(17),
  ee_div_no        CHAR(4),   src_i            DEC(17)
);

-- (2) Upload from Excel: NEW account_no, soc_sec_no, def_adj_p, def_adj_a, src_i

-- (3) Rehydrate keys
UPDATE savexpresscopy a
SET ee_div_no = (SELECT ee_div_no FROM corp.vemployee b
                  WHERE case_no = account_no AND a.soc_sec_no = b.soc_sec_no);

UPDATE savexpresscopy a
SET enrl_prov_grp_i = (SELECT DISTINCT enrl_prov_grp_i FROM pension.plan_prov_grp b
                        WHERE a.account_no = b.account_no
                          AND RELATED_GRP_TYP_C = 361),
    part_enrl_i = (SELECT part_enrl_i FROM pension.part_enrl b,
                          pension.person_search c, pension.plan_prov_grp d
                    WHERE d.account_no = a.account_no
                      AND part_i = person_i
                      AND d.enrl_prov_grp_i = b.enrl_prov_grp_i
                      AND a.soc_sec_no = c.soc_sec_no
                      AND RELATED_GRP_TYP_C = 361),
    eff_d = '2009-01-01',           -- contract effective date
    def_grp_i = (SELECT def_grp_i FROM pension.plan_deferral_grp b,
                       pension.plan_prov_grp c
                  WHERE b.enrl_prov_grp_i = c.enrl_prov_grp_i
                    AND b.src_i = a.src_i),
    div_i = (SELECT org_i FROM pension.p2_div_xref b
              WHERE b.case_no = a.account_no
                AND a.ee_div_no = b.div_no);

-- (4) Insert into live PART_AUTO_DEF
INSERT INTO pension.part_auto_def
  (PART_ENRL_I, ENRL_PROV_GRP_I, ACCOUNT_NO, SOC_SEC_NO, EFF_D,
   DEF_ADJ_P, DEF_ADJ_A, STAT_C, SRC_C, DEF_GRP_I, UPD_REASON_C,
   USER_I, MOD_TS, DIV_I)
SELECT PART_ENRL_I, ENRL_PROV_GRP_I, ACCOUNT_NO, SOC_SEC_NO, EFF_D,
       DEF_ADJ_P, DEF_ADJ_A, 0, SRC_C, DEF_GRP_I, 'B',
       'UYN024', CURRENT TIMESTAMP, DIV_I
FROM savexpresscopy;
