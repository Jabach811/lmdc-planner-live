§ 06–07

Mapping · the crosswalks.

Source mapping is built from prior-RK test files and required for every method. Fund mapping is built from the signed TOA and required only when assets actually move (Mapping + TIK). Both go to QA / TC / TM before the run.

§ 03–05

The three balance-import methods.

Pick the method by what the prior RK delivers — a wire (Cash), a one-shot file pair with a QA gate (Mapping), or registered shares with a custodian setup (TIK). Each has its own gates, its own audit surfaces, and its own way of failing.

03 · CASH Method A

Cash conversion

Wire arrives at Advance Employer holding, waits for the final file, then distributes to participants per election. No fund mapping.

§ When

The order these run in.

A simplified ledger of when each procedure happens relative to the conversion event. Pre-work and mapping land before the run; the chosen method is the run; reconciliation closes it.

Read the matching procedure page first Each page has the SQL, decision branches, and gate sequence specific to that procedure. The index is a map; the pages are the territory.
Source mapping isn't optional anywhere Even Cash Conversion needs source mapping — what it doesn't need is fund mapping. If you've been asked to skip source mapping for a cash run, push back.
Don't pick the method yourself The method is determined by what the prior RK delivers and what the receiving plan accepts — not by what's convenient. Confirm conversion type with the project owner before any pre-work begins.
